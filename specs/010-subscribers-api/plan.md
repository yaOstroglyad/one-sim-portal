- subscriber-summary (KPI cards)
- network-statuses (network status chart)

## Phase 1: Design

### Data Model

API response interfaces (to be added to `subscribers.types.ts`):

```typescript
// Query parameters for all 4 endpoints
interface SubscriberReportParams {
  accountId: string;
  period: string;
  dateFrom: string;  // ISO 8601
  dateTo: string;    // ISO 8601
}

// 1. subscriber-summary
interface SubscriberSummaryResponse {
  newSubscribers: number;
  downloadedSims: number;
  activeSubscribers: number;
  spentBundles: number;
  avrBundleSize: number;
}

// 2. network-statuses & 4. bundle-statuses (shared structure)
interface PeriodStatusesResponse {
  periodStatuses: PeriodStatus[];
}

interface PeriodStatus {
  period: string;
  totalCount: number;
  statuses: StatusCount[];
}

interface StatusCount {
  status: string;
  count: number;
}

// 3. bundle-subscribers
interface BundleSubscribersResponse {
  subscribersByBundle: BundleGroup[];
  subscribersByCountry: BundleGroup[];
}

interface BundleGroup {
  groupName: string;
  subscribers: number;
  statuses: StatusCount[];
}
```

### API Contracts

All endpoints use GET method with query parameters:

| Endpoint | Response Type |
|----------|---------------|
| `/api/v1/reports/dashboards/subscribers/subscriber-summary` | `SubscriberSummaryResponse` |
| `/api/v1/reports/dashboards/subscribers/network-statuses` | `PeriodStatusesResponse` |
| `/api/v1/reports/dashboards/subscribers/bundle-subscribers` | `BundleSubscribersResponse` |
| `/api/v1/reports/dashboards/subscribers/bundle-statuses` | `PeriodStatusesResponse` |

### Implementation Steps

1. **Enable tab** - Remove `disabled: true` from subscribers tab config
2. **Add API config** - Add 4 endpoint URLs to `config.utils.ts`, set `subscribers: false` in mock config
3. **Add types** - Replace mock types with API response interfaces in `subscribers.types.ts`
4. **Add service methods** - Add 4 API methods to `dashboard-data.service.ts` using forkJoin pattern
5. **Redesign component** - Update `subscribers-tab.component.ts` to call new service methods
6. **Redesign template** - Update HTML with new layout (5 KPIs + 3 chart sections)
7. **Update styles** - Adjust SCSS for new layout
