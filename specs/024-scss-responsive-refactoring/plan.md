# Implementation Plan: SCSS Responsive Architecture Refactoring

**Branch**: `024-scss-responsive-refactoring` | **Date**: 2026-01-22 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/024-scss-responsive-refactoring/spec.md`

## Summary

Refactor SCSS architecture to create a fully adaptive application that works on all devices (320px-2560px viewport) with centralized breakpoint variables and reusable layout mixins. The implementation eliminates ~111 lines of duplicated layout styles, replaces 79 hardcoded breakpoints with mixin calls, and introduces a new `$layout-breakpoint: 900px` (calculated: 256px sidebar + 600px min content) to properly support modern devices including phones in landscape mode.

## Phase 0: Research Findings

### Research Task 1: Breakpoint Values Analysis

**Decision**: Use 900px as layout breakpoint

**Rationale**:
- Current 768px doesn't account for phones in landscape (iPhone 14 Pro Max = 932px)
- Calculation: 256px (sidebar) + 600px (minimum content) = 856px → rounded to 900px
- This ensures adequate content space when sidebar is visible

**Alternatives Considered**:
- 850px: Too close to calculation, no buffer
- 1024px: Too aggressive, hides sidebar on many tablets
- Bootstrap 992px: Doesn't match our sidebar + content calculation

### Research Task 2: Existing Mixin Usage

**Decision**: Extend existing mixins, don't replace

**Rationale**:
- `mobile`, `tablet`, `desktop` mixins exist but only used in 4 of 79 places
- Adding `layout-mobile` and `layout-desktop` for layout-specific breakpoint
- Adding `breakpoint-down($size)` and `breakpoint-up($size)` for generic usage
- Existing mixins updated to use centralized variables

**Alternatives Considered**:
- Replace all existing mixins: Breaking change, unnecessary
- Use CSS Container Queries: Not needed for this use case, less browser support

### Research Task 3: Layout Duplication Strategy

**Decision**: Create layout mixins in `_mixins.scss`

**Rationale**:
- `docs-layout.component.scss` duplicates ~111 lines from `default-layout.component.scss`
- Extract common patterns to mixins: `layout-base`, `layout-main-base`, `layout-mobile-overlay`
- Both layouts include these mixins + their specific additions

**Alternatives Considered**:
- Separate `_layout-base.scss` file: Adds file, mixins belong in `_mixins.scss`
- CSS inheritance via `:host ::ng-deep`: Anti-pattern, breaks encapsulation

### Research Task 4: RTL Support Pattern

**Decision**: Use existing `layout--rtl` class with CSS logical properties where possible

**Rationale**:
- RTL already works via `layout--rtl` modifier class
- Mobile sidebar slides from right in RTL mode
- Mixins will include RTL variants using existing pattern

### Research Task 5: Reduced Motion Support

**Decision**: Add `prefers-reduced-motion` media query to transition mixins

**Rationale**:
- Accessibility requirement from spec edge cases
- Existing `chart-accessibility` mixin provides pattern
- Transitions should be instant when user prefers reduced motion

## Phase 1: Design

### 1.1 Breakpoint Variables Design

Add to `_variables.scss`:

```scss
// ==============================================
// RESPONSIVE BREAKPOINTS
// Mobile-first approach based on content needs
// ==============================================

// Content breakpoints (for component adaptation)
$breakpoint-sm: 480px !default;   // Phone portrait max
$breakpoint-md: 768px !default;   // Tablet portrait max
$breakpoint-lg: 1024px !default;  // Tablet landscape max
$breakpoint-xl: 1280px !default;  // Laptop max
$breakpoint-xxl: 1440px !default; // Desktop

// Layout breakpoint (for sidebar behavior)
// Sidebar hides when: viewport < sidebar-width + minimum-content-width
// 256px (sidebar) + 600px (min content) = 856px → rounded to 900px
$layout-breakpoint: 900px !default;
```

### 1.2 Layout Mixins Design

Add to `_mixins.scss` after existing responsive mixins:

```scss
// ==============================================
// RESPONSIVE BREAKPOINTS (Content)
// Use for component-level responsive styles
// ==============================================

/// Apply styles at or below a breakpoint
/// @param {String} $size - Breakpoint name (sm, md, lg, xl)
@mixin breakpoint-down($size) {
  @if $size == 'sm' {
    @media (max-width: vars.$breakpoint-sm) { @content; }
  } @else if $size == 'md' {
    @media (max-width: vars.$breakpoint-md) { @content; }
  } @else if $size == 'lg' {
    @media (max-width: vars.$breakpoint-lg) { @content; }
  } @else if $size == 'xl' {
    @media (max-width: vars.$breakpoint-xl) { @content; }
  } @else if $size == 'xxl' {
    @media (max-width: vars.$breakpoint-xxl) { @content; }
  }
}

/// Apply styles above a breakpoint
/// @param {String} $size - Breakpoint name (sm, md, lg, xl)
@mixin breakpoint-up($size) {
  @if $size == 'sm' {
    @media (min-width: vars.$breakpoint-sm + 1) { @content; }
  } @else if $size == 'md' {
    @media (min-width: vars.$breakpoint-md + 1) { @content; }
  } @else if $size == 'lg' {
    @media (min-width: vars.$breakpoint-lg + 1) { @content; }
  } @else if $size == 'xl' {
    @media (min-width: vars.$breakpoint-xl + 1) { @content; }
  } @else if $size == 'xxl' {
    @media (min-width: vars.$breakpoint-xxl + 1) { @content; }
  }
}

// ==============================================
// LAYOUT BREAKPOINTS (Sidebar/Header)
// Use for layout-level responsive styles
// ==============================================

/// Apply styles when in mobile layout mode (sidebar hidden)
@mixin layout-mobile {
  @media (max-width: vars.$layout-breakpoint) {
    @content;
  }
}

/// Apply styles when in desktop layout mode (sidebar visible)
@mixin layout-desktop {
  @media (min-width: vars.$layout-breakpoint + 1) {
    @content;
  }
}

// ==============================================
// LAYOUT COMPONENT MIXINS
// Shared styles for default-layout and docs-layout
// ==============================================

/// Base layout container styles
@mixin layout-base {
  display: flex;
  min-height: 100vh;
  background: var(--layout-frame-bg);
  color: var(--layout-frame-text);
  transition: background 0.3s ease, color 0.3s ease;

  @media (prefers-reduced-motion: reduce) {
    transition: none;
  }
}

/// Main content area styles
@mixin layout-main-base {
  flex: 1;
  display: flex;
  flex-direction: column;
  margin-left: vars.$layout-sidebar-width;
  overflow-x: hidden;
  overflow-y: auto;
  padding-top: vars.$layout-header-height;
  height: 100vh;
  box-sizing: border-box;
  transition: margin-left 0.3s cubic-bezier(0.4, 0, 0.2, 1);

  @include layout-mobile {
    margin-left: 0;
    margin-right: 0;
  }

  @media (prefers-reduced-motion: reduce) {
    transition: none;
  }
}

/// RTL variant for main content
@mixin layout-main-rtl {
  margin-left: 0;
  margin-right: vars.$layout-sidebar-width;

  @include layout-mobile {
    margin-right: 0;
  }
}

/// Mobile overlay backdrop styles
@mixin layout-mobile-overlay {
  position: fixed;
  top: vars.$layout-header-height;
  left: 0;
  right: 0;
  bottom: 0;
  background: rgba(0, 0, 0, 0.5);
  z-index: 999;
  opacity: 0;
  visibility: hidden;
  transition: all 0.3s ease;

  &--visible {
    opacity: 1;
    visibility: visible;
  }

  @include layout-desktop {
    display: none;
  }

  @media (prefers-reduced-motion: reduce) {
    transition: none;
  }
}

/// Content container styles
@mixin layout-content-base {
  flex: 1;
  display: flex;
  flex-direction: column;
  min-height: 0;
  padding: 1.5rem;

  @include layout-mobile {
    padding: 1rem;
  }
}

/// Container wrapper styles
@mixin layout-container-base {
  flex: 1;
  display: flex;
  flex-direction: column;
  min-height: 0;
  overflow: hidden;
}
```

### 1.3 Migration Pattern

For each component file with hardcoded breakpoints:

**Before:**
```scss
@media (max-width: 768px) {
  display: none;
}
```

**After (for content components):**
```scss
@include mixins.breakpoint-down('md') {
  display: none;
}
```

**After (for layout components):**
```scss
@include mixins.layout-mobile {
  display: none;
}
```
